缩放点积与归一化

Attention 用 Query 与 Key 的匹配分数生成权重，再对 Value 向量加权求和。Softmax 只负责把一行分数归一化，权重不是最终输出。

数量与分数差如何影响权重

固定目标与等分背景的分数差为 Δ 时，目标权重是 1 / (1 + N exp(−Δ))。完整文章逐步推导分母与 ln N 的关系，并区分局部权重、输出向量和实际任务表现。
