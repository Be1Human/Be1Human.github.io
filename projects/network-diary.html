macOS / Windows 应用·桌面网络观察工具

大小姐的网络手账

面向 Claude Code 的 macOS / Windows 网络观察工具。按采样记录候选出口 IP、变化历史和同一非中国 / 非香港出口 IP 的连续稳定时长，支持本地历史、托盘常驻与 CSV 导出。

同一个出口维持了多久

总览记录 Claude Code 模型服务探测路径观测到的出口 IP。地址归属明确且符合计时条件时，同一个 IP 连续出现才累计时长。换 IP、探测失败或休眠造成采样缺口时，记录会停在最后一次确认的时间。

遇到一次变化时怎么查

在历史里查看变化发生的时间、所用探测路径和前后地址。浏览器近似路径与模型服务探测结果分别显示，便于判断两条路径在同一时段看到的出口是否一致。

本机保存与导出

应用可在 macOS 或 Windows 托盘中继续采样。历史保存在本机 SQLite 数据库，可以筛选记录或导出 CSV。地理归属采用第三方估计。
