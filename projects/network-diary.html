桌面网络观察工具

大小姐的网络手账

这是一个桌面网络观察工具，用来记录 Claude Code 相关连接看到的出口 IP 和变化历史。

两条探测路径可能看到不同出口，采样之间也可能发生休眠。工具分别记录来源，连续计时只覆盖满足条件且被实际观测到的那段时间。

从采样到可复查的连续区间

观测
  1. 独立工作进程发起限时探测
  2. 带来源样本时间、路径、出口
  3. 本地 SQLite追加历史记录
计时
  1. 相邻有效样本同一个合格出口
  2. 中断条件换址、失败或采样缺口
  3. 区间结算止于最后确认时间

总览使用演示数据，分别显示当前出口、已确认时长与中断记录。

采样来源与连续计时规则

为什么要区分探测路径

模型服务域名边缘看到的候选出口，与独立 Chromium 会话按系统代理观测到的出口可能不同。两类样本分别保留时间、路径和地址，避免把路由差异误读成一次地址切换。

连续时长的判定边界

计时限定在同一模型服务探测路径、归属明确且符合计时条件的出口。换址、探测失败或休眠缺口都会中断区间。上一段只累计到最后一次有效确认，恢复后重新计时。

后台进程与本地历史

Electron 将网络采样和 SQLite 放在独立工作进程。单轮请求设有超时，轮询互不重叠；窗口收起后后台继续采样。历史与检查点保存在本机，可用于恢复计时和导出 CSV。
