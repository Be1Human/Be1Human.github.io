Groki：ESP32-S3 接入 Grok 原生语音 ↗

Groki 将 M5Stack CoreS3 等受支持 ESP32-S3 设备接成 Grok Bot 语音终端。原生语音路径仅支持 macOS，需要同网 Mac、持续运行的网关和已登录的 Grok Bot 桌面端；文档说明使用内部接口，应用更新可能使其失效。主代码为 Boost、网关为 MIT，但发布固件含 Emotion Ball 非商用数据，不能直接认定整套固件可自由商用；无需独立 xAI 语音 API Key，也不代表订阅额度无限。

Omarchy Local Live Sub：离线中英双语字幕 ↗

Nero 的 Omarchy Local Live Sub 面向 x86_64 Omarchy / Arch Linux 的面对面交流，用 SenseVoice Small 识别语音、Hy-MT2 经 llama.cpp 做中英双向翻译，在同屏显示原文与译文。首次安装需联网下载约2.85GB模型，随后可离线；至少16GB内存，推荐32GB，明确验证的是 Intel Core Ultra 9 285H 与集显。应用代码 MIT，模型另遵循上游许可；仅输出文字，不提供译文语音，分句设置不等于端到端延迟保证。

Audio Studio MCP：本地游戏配乐与音效 ↗

Audio Studio MCP 是接入 Claude Code、Cursor 等 MCP 客户端的本地音频工具，使用 Stable Audio 3 生成配乐、乐器循环与音效，并支持局部重做、续写和 WAV／OGG／FLAC 导出。当前仓库已支持 Apple Silicon Mac 与 Windows NVIDIA GPU；Windows 建议至少8GB显存，并需 Hugging Face 账号接受模型许可。代码为 MIT，模型使用另受 Stability Community License 约束，免费商用范围有总年收入低于100万美元等条件。未安装或复现作者速度数据。
