ESP Emulator：不用开发板运行固件 ↗

Espressif 的 ESP Emulator 可在桌面或浏览器中运行所支持 ESP32 芯片的 ESP-IDF 固件，适合先验证软件流程。目前仍属 Beta；公开仓库分发安装器、预编译程序、文档和辅助工具，不能据此称模拟器核心全部开源。浏览器托管版不支持直接联网，硬件时序与外设表现仍需实机验证。

Desigma：Rust 原生 UI 设计编辑器 ↗

Desigma 是不依赖 Electron 的 Rust 原生 UI 设计工具，支持导入 .fig 与 Figma REST JSON，并提供布局、组件、向量与 MCP 文件会话能力。代码采用 MIT 或 Apache-2.0。项目仍处于早期 Alpha，真实 .fig 文件兼容性有缺口，部分字体需要下载，不宜理解为成熟 Figma 替代品或始终完全离线。

Eleven：Agent 辅助逆向分析工作台 ↗

Eleven 将支持 ACP 的 Agent 接入逆向分析界面，支持二进制、APK 等文件，并整合 Ghidra、Rizin、jadx 等外部工具。项目采用 Apache-2.0，覆盖 macOS、Windows 与 Linux，但架构和系统版本有要求，依赖外部分析工具，首次启动可辅助安装，模型服务费用也不包含在内。补丁以提案和副本方式处理，使用范围应限于获授权的程序。
